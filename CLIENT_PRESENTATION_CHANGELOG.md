## Repository audit before edits

- The repository used the Next.js App Router, TypeScript, React, Tailwind CSS, local WebP images and Next.js image optimization. The README specifies the Vercel Next.js runtime and a Resend-backed enquiry endpoint with an email draft fallback. The checkout contains no linked Sites or Vercel project configuration.
- Existing routes covered Home, About, Services and six service details, Facilities, Projects and 22 project records, QHSE, Contact, Careers and legal policies. Project filters, dialog galleries, mobile navigation, enquiries, redirects and SEO were already implemented.
- Dubai Marina Mall, District Cooling Plant 1 and Dubai International Airport Concourse IV overlap the supplied deck. All three keep their existing URLs. The older Al Habtoor City and tennis court packages have different scopes and project teams, so they remain separate historical records.
- The old homepage used an unlabeled erection image and repeated the same workshop image. The old projects header used an unattributed background, the facilities dispatch image was a site layout rendering, and signature works lacked steel-package galleries. The legacy project-list page also repeated the World Trade Center filename at the cooling plant entry. A visual comparison confirmed that the repository’s `cooling-detail.webp` and slide 28 show the same cooling plant.
- Some historical pages were image-and-caption entries. Party placeholders on the legacy source were already withheld. Those pages remain available with their source-supported details.
- The homepage used scroll-linked hero movement and a dedicated mobile hero source. The expanded copy and longer name strings made narrow-screen wrapping a priority. The previous README records a 93 mobile Lighthouse score from the earlier build for context.
